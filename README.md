# DevLabs Technology Website Manual Testing

## Overview

This repository contains manual testing scenarios created while testing the DevLabs Technology public website.

The test scenarios are documented in **BDD (Behavior-Driven Development) / Gherkin format** and focus on functional behavior, navigation, form validation, and user interactions across different areas of the website.

## Testing Areas

The test scenarios cover the following areas:

- Navigation
- Services
- Contact Flow
- About Us
- Hire a Developer
- Homepage
- Contact Form Validation
- Form Submission and Validation
- Website Navigation and Page Verification

## Test Scenarios

The repository contains **31 manual test scenarios** covering positive and negative testing scenarios across the DevLabs Technology website.

The scenarios include:

- Page navigation and URL verification
- Service navigation
- Form submission
- Email validation
- Address field validation
- Required field validation
- Website content verification
- Button and link functionality
- Navigation through different website sections
